Steps to connect to MongoDB Atlas from MongoShell:

1. Create a project on https://cloud.mongodb.com/
2. Create a cluster
3. Create a database
4. Create a collection
5. Connect to the cluster using the connection string

In MacOS:

1. Install MongoSheel in MacOS
 brew install mongosh

2. Connect to the cluster using the connection string
Example:
mongosh "mongodb+srv://cluster0.hwyayk5.mongodb.net/" --apiVersion 1 --username akashmurumkar --password QSS9gltvYV4OngrN

In Java:

1. Create a connection object
2. Create a database object
3. Create a collection object

Example: Refer to the code - MongoClientConnectionExample in helper package
